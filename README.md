# ✨ JavaScript Quiz Game

A visually stunning, modern web-based **Quiz Game** featuring a premium **Vanilla JS + CSS frontend**. Test your knowledge with dynamic trivia powered by the OpenTDB API, presented in a glorious glassmorphic gaming dashboard!

## 🚀 Features

- 🎨 **Glorious UI**: Beautifully crafted, responsive interface featuring intense glassmorphism, fluid micro-animations, and ambient dynamic background effects.
- 🧠 **Real-Time Trivia**: Connects live to OpenTDB API to fetch diverse quiz questions instantly.
- 🎚️ **Dynamic Quiz Control**: Comprehensive Main Menu allows users to customize the length of their session using a sleek neon slider (5–50 questions).
- ⏱️ **High-Stakes Timer**: A ticking race against time per question to maintain an urgent arcade thrill.
- 🏆 **Highscore Tracking**: Native persistence storage systematically collects and ranks your top 10 best career scores.
- ✨ **Semantic Contextualism**: Clean, text-based difficulty badges (Easy, Medium, Hard) color-coded with high-quality neon glows automatically adjusting point value logic.
- 📊 **Visual Progression**: Features a liquid-plasma progress bar that animates smoothly as you resolve queries.

## ⚙️ How It Works

1. **Initialization**: Users specify their ideal question load from the immersive entry portal.
2. **Data Fetching**: Contacts the OpenTDB gateway, gracefully isolating HTML-encoded streams for safe layout construction.
3. **Game Logic**: Users pick answers and finalize commitments via locked submission gates.
4. **Visual Grading**: The engine highlights right and wrong selections visually while accumulating score weights according to difficulty class.
5. **Cycle Completion**: Highscores are automatically updated locally and the terminal display prepares the full replay gateway.

## 🚦 Getting Started

### 📋 Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari)
- Active internet connection (required for OpenTDB question streaming)

### 💾 Installation

1. Clone this repository to your local machine:

```bash
git clone https://github.com/HeX-ecutioner/quiz-game.git
```

2. Navigate to the project subdirectory:

```bash
cd quiz-game
```

### 🎮 Running the Game Locally

Seamlessly open the `index.html` file directly in your favorite browser!
